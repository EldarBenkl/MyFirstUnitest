## Цели и задачи тестирования
Протестировать функцию `area` на корректность вычисления площади прямоугольника и соблюдение ограничений на входные данные.

## Описание тестируемого продукта
Функция `area` возвращает произведение сторон прямоугольника.

Требования:
* Стороны не должны быть отрицательными.
* На вход подаются только числовые типы данных (`int`, `float`).

## Область тестирования
Функция `area`:
```py
def area(a, b):
    if a < 0 or b < 0:
        raise ValueError("Стороны не могут быть отрицательными")
    return a * b
```
Функция принимает числовые параметры `a` и `b` и возвращает их произведение. Если хотя бы одна из сторон является отрицательной, функция вызывает исключение `ValueError`.

## Стратегия тестирования
Для проверки модуля применяется модульное тестирование **(unittest)** с использованием встроенного фреймворка `unittest`. 

Основные направления и техники:
* **Функциональное тестирование (позитивное и негативное):** проверка корректности расчетов на валидных данных и проверка выброса исключений (`ValueError`, `TypeError`) при передаче некорректных значений.
* **Методы «черного» и «белого» ящика:** проверка соответствия математической формуле и полное покрытие ветвлений кода (`if a < 0 or b < 0`).
* **Техники тест-дизайна:** эквивалентное разделение (целые, дробные, отрицательные числа, строки) и анализ граничных значений (нулевые и большие значения).
* **Тестирование производительности и безопасности:** проверка скорости вычислений на больших числах и устойчивости функции к передаче нечисловых типов данных.

## Критерии приемки
* Все модульные тесты из набора `RectangleTestCase` завершаются со статусом `PASS` (`OK`).
* Функция корректно вычисляет площадь для неотрицательных чисел (`a >= 0`, `b >= 0`).
* Функция корректно обрабатывает отрицательные значения (вызывает `ValueError`) и нечисловые типы данных (вызывает `TypeError`).
